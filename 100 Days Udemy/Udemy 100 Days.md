# Udemy 100 Days of Code

## URL

https://www.udemy.com/course/100-days-of-code/

## Virtual Environment

Venv was created using uv (`uv venv udemy100days`). To use the venv:

```
uv run python3 DayX.py
```

Alternatively:

```
source udemy100days/bin/activate
python3 DayX.py
```

## Daily Code Projects

1. Band name generator: inputs.
2. Tip calculator: converting types, numeric operations, f-strings.
3. Choose your own adventure: conditional statements.
4. Rock, paper, scissors: random numbers.
5. Password generator: loops.
6. ...
